Piper (optioneel)
------------------
Plaats hier een Nederlandse Piper .onnx stem + bijbehorende .onnx.json.
De monitor gebruikt Piper automatisch als `piper` is geïnstalleerd.
Je kunt ook P2000_PIPER_MODEL naar een .onnx-bestand laten wijzen.
Zonder Piper blijft Linux automatisch terugvallen op eSpeak en daarna Nederlandse online TTS.
