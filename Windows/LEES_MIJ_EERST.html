WINDOWS 10/11 • v4.4.18

P2000 Monitor — Windows

Deze map is een complete, zelfstandige Windows-installatie. Linux-bestanden zijn bewust niet opgenomen.

1. Starten

Aanbevolen

Dubbelklik INSTALL_P2000.bat. De installer controleert de Windows-runtime en start daarna de monitor.

Portable

Dubbelklik START_P2000.bat.

Beheer: OPEN_INSTELLINGEN.bat
Wizard: CONFIGURATIE_WIZARD.bat
Diagnose: WINDOWS_CHECK.bat

2. Windows-fixes in v4.4.18

  • Een P2000-kiosk van een oude versie wordt bij de start automatisch gesloten; een kiosk van dezelfde versie blijft staan.
  • Edge en Chrome krijgen een versiegebonden browserprofiel en de URL bevat een cachebuster. Daardoor kan een oude frontend niet meer naast een nieuwe backend blijven hangen.
  • Windows-TTS gebruikt eerst de normale audiolaag. Als Chromium niets afspeelt, kan de lokale kiosk terugvallen op Windows System.Media.SoundPlayer.
  • Tankautospuit wordt uitgesproken als “T S”. Het roepnummer zelf blijft uit de omroeptekst.
  • Testmeldingen kunnen via dezelfde backend ook een lichtkrant in een ander venster, browser of apparaat bereiken.

3. Omroep / TTS

De backend kan lokaal Windows SAPI-audio genereren. De host-audiofallback is om veiligheidsredenen alleen vanaf localhost beschikbaar; een extern apparaat kan dus niet zomaar audio op deze Windows-pc starten.

Stemcontrole/installatie: INSTALL_NEDERLANDSE_STEM.bat.

4. Kiosk en scherm

De Windows-starter gebruikt Edge of Chrome met een apart P2000-profiel. De gekozen monitorpositie komt uit de Windows monitor-API. Bij een update wordt uitsluitend een aantoonbaar oudere P2000-kiosk vervangen.

5. GitHub-updates

Een gecombineerde release met Windows/ en Linux/ wordt ondersteund. Op Windows kiest de updater automatisch alleen de Windows/-map.

Aanbevolen releasebestand: P2000_Monitor_v4.4.18_Windows_Linux.zip.

6. Problemen oplossen

  • WINDOWS_CHECK.bat — volledige diagnose.
  • START_BACKEND.bat — backend zichtbaar starten om fouten te zien.
  • STOP_P2000.bat — monitor en P2000-kiosk stoppen.
  • HERSTEL_VORIGE_VERSIE.bat — vorige update terugzetten.
