P2000 MONITOR v4.4.18 — WINDOWS
================================

AANBEVOLEN
1. Pak de volledige Windows-map uit.
2. Start INSTALL_P2000.bat.
3. Rond bij de eerste start de configuratiewizard af.

PORTABLE
Start START_P2000.bat.

INSTELLINGEN
OPEN_INSTELLINGEN.bat

DIAGNOSE
WINDOWS_CHECK.bat

NEDERLANDSE WINDOWS-STEM
INSTALL_NEDERLANDSE_STEM.bat

BELANGRIJK v4.4.18
- Oude P2000 Edge/Chrome-kiosks uit een vorige versie worden automatisch vervangen.
- Browserprofielen zijn versiegebonden; dezelfde versie wordt niet onnodig afgesloten.
- Als browseraudio op de lokale Windows-kiosk faalt, gebruikt de monitor automatisch
  Windows host-audio als fallback.
- TS wordt uitgesproken als "T S"; roepnummers worden niet voorgelezen.
