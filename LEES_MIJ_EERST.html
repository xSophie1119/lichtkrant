WINDOWS 10/11 + LINUX • v4.4.11

P2000 Monitor MultiPlatform

Dezelfde lichtkrant, configuratie, parser, voertuigdatabase en GitHub-updater draaien nu op Windows én Linux. Alleen onderdelen die echt OS-specifiek zijn — browserstart, monitor-API en lokale spraak — worden automatisch per platform gekozen.

1. Snel starten

Windows

Dubbelklik START_P2000.bat. De meegeleverde bootstrap controleert/herstelt automatisch de eigen Python-runtime en start daarna backend + kioskbrowser.

Beheer: OPEN_INSTELLINGEN.bat
Wizard: CONFIGURATIE_WIZARD.bat
Diagnose: WINDOWS_CHECK.bat

Linux

chmod +x *.sh
./START_P2000.sh

Linux gebruikt een aanwezige Python 3.10+ en zoekt automatisch Chrome/Chromium/Brave/Edge; Firefox is fallback.

Beheer: ./OPEN_INSTELLINGEN.sh
Wizard: ./CONFIGURATIE_WIZARD.sh
Diagnose: ./LINUX_CHECK.sh

2. Linux-pakketten

De monitor heeft geen verplichte pip-installatie nodig. Voor de beste kioskervaring zijn een Chromium-browser en eSpeak NG aanbevolen.

sudo apt install python3 chromium espeak-ng x11-xserver-utils

Op Wayland is wlr-randr optioneel voor wlroots-compositors. GNOME/KDE Wayland laten scherm-power niet altijd veilig door een gewone app regelen; de monitor meldt dat dan netjes in plaats van een fout te forceren.

3. Omroep / TTS

PlatformPrimaire routeFallback
WindowsLokale Windows SAPI → WAVgTTS → MP3
LinuxLokale Nederlandse eSpeak/eSpeak NG → WAVgTTS → MP3

De aandachtstoon wordt bij lokale WAV-spraak in dezelfde audiofile geplaatst. Browservolume blijft leidend; de applicatie verandert niet ongevraagd het globale systeemvolume.

4. Schermen en kiosk

Windows gebruikt de native monitor-API. Linux probeert xrandr (X11) of wlr-randr (wlroots Wayland), met een veilige fallback als geen hardware-API beschikbaar is. De gekozen monitorpositie wordt door de kioskstarter gebruikt voor plaatsing en fullscreen.

Scherm aan/uit gebruikt Windows SC_MONITORPOWER, X11 xset of wlroots wlr-randr. Niet-ondersteunde Wayland-desktops krijgen een duidelijke melding.

5. Instellingen en opslag

Configuratie blijft lokaal in de config-map staan en wordt atomisch opgeslagen. Daardoor blijven lichtkrantinstellingen, profiel, regio's, steden, geluid en schermkeuze na herstart bewaard. GitHub-instellingen kunnen centraal worden gesynchroniseerd zonder lokale runtimebestanden te overschrijven.

6. GitHub-updates

De updater ondersteunt Release-assets én branch/SHA-updates. Een Release met MultiPlatform in de bestandsnaam krijgt voorrang. Daarna kiest de updater waar mogelijk het passende Windows- of Linux-asset. Linux-uitvoerrechten op .sh-launchers worden na een update hersteld.

Aanbevolen Release-bestand: P2000_Monitor_MultiPlatform_v4.4.11.zip.

7. Autostart

Windows

INSTALL_AUTOSTART.bat / REMOVE_AUTOSTART.bat

Linux

./INSTALL_AUTOSTART.sh / ./REMOVE_AUTOSTART.sh. Dit maakt een XDG-autostart entry na grafische login.

8. Problemen oplossen

  • Backend zichtbaar starten: START_BACKEND.bat of ./START_BACKEND.sh.
  • Linux complete check: ./LINUX_CHECK.sh.
  • Windows complete check: WINDOWS_CHECK.bat.
  • Linux lokale stem check: ./INSTALL_NEDERLANDSE_STEM.sh.
  • Alles stoppen: STOP_P2000.bat of ./STOP_P2000.sh.
  • Vorige update terugzetten: HERSTEL_VORIGE_VERSIE.bat of ./HERSTEL_VORIGE_VERSIE.sh.
