LINUX • v4.4.18

P2000 Monitor — Linux

Deze map is een complete, zelfstandige Linux-installatie. Windows-batch- en PowerShell-bestanden zijn bewust niet opgenomen.

1. Starten

Aanbevolen

chmod +x *.sh tools/*.py
./INSTALL_P2000.sh

Portable

./START_P2000.sh

Beheer: ./OPEN_INSTELLINGEN.sh
Wizard: ./CONFIGURATIE_WIZARD.sh
Diagnose: ./LINUX_CHECK.sh

2. Linux-onderdelen

Voor de beste kioskervaring zijn Python 3.10+, Chromium/Chrome en eSpeak NG aanbevolen.

sudo apt install python3 chromium espeak-ng x11-xserver-utils

Op Wayland is wlr-randr optioneel. GNOME/KDE Wayland staan scherm-power niet altijd toe; de monitor valt dan veilig terug.

3. Omroep / TTS

Linux gebruikt lokaal Nederlandse eSpeak/eSpeak NG-audio waar beschikbaar en heeft de bestaande online audiovariant als fallback. Tankautospuit wordt uitgesproken als “T S”; roepnummers blijven uit de omroeptekst.

Stemcontrole/installatie: ./INSTALL_NEDERLANDSE_STEM.sh.

4. Kiosk en scherm

Linux gebruikt xrandr op X11 of wlr-randr waar beschikbaar op wlroots-Wayland. Chrome/Chromium/Brave/Edge worden automatisch gezocht; Firefox is fallback.

5. GitHub-updates

Een gecombineerde release met Windows/ en Linux/ wordt ondersteund. Op Linux kiest de updater automatisch alleen de Linux/-map en herstelt hij uitvoerrechten van shellstarters.

Aanbevolen releasebestand: P2000_Monitor_v4.4.18_Windows_Linux.zip.

6. Problemen oplossen

  • ./LINUX_CHECK.sh — volledige diagnose.
  • ./START_BACKEND.sh — backend zichtbaar starten om fouten te zien.
  • ./STOP_P2000.sh — monitor/kiosk stoppen.
  • ./HERSTEL_VORIGE_VERSIE.sh — vorige update terugzetten.
